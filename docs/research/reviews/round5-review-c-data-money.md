## What Is Already Good

- DATA-3, DATA-5, DATA-45 and DATA-59 already provide append-only money records, command fingerprints and event-consumer deduplication. Extend these mechanisms rather than inventing replacements.
- Composite tenant FKs, restricted deletion and TEN-19’s exactly-one-scope classification provide a strong isolation baseline.
- BILL-27 correctly separates settlement from performance; B-04/BILL-12 preserve patient balance as a non-expiring liability.
- BILL-28 already defines discount effects on tax, package values and commission; BILL-29 prevents simulated payments from creating real entitlements.
- PR-97 correctly treats expert output as evidence, and P-24 correctly makes family sharing opt-in rather than universally enabled. The remaining work is propagating those decisions into the authoritative data and money contracts.
