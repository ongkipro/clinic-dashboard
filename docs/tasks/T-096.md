## 4. OTP (P1-2) — synchronous, outside the queue
- `sendAftercareOtp(pool, token, ip, { now, port })` (src/modules/crm/aftercare/aftercare.ts): a 6-digit code (crypto randomInt), sha256;
  unbound definer `aftercare_otp_send(p_token_hash, p_otp_hash, p_ip_hash, p_now)`: refuses a bound connection; staff_access lock; tenant
  lifecycle onboarding | live | suspended (PR-56); link expiry; otp_locked_until; RATE-1 (≤ 3 sends per 10 min per phone across the
  tenant, ≤ 10 per min per ip_hash) from aftercare_otp_sends; sets otp_hash, otp_expires_at = now + 5 min, otp_attempts = 0; logs the send;
  returns the WABA route + sealed token + wrapped DEKs (the 0109 claim shape). TS opens the token and calls `port.sendMessage` with the
  approved `authentication` template `kode_otp` (params [code]). Refusals (not_found, link_expired, otp_locked, rate_limited,
  number_not_sending) return { ok: false, reason } without raising, so the rate-limit row commits (0066:123 pattern). No outbound_messages
  or messages row (an OTP is not a conversation message). The mock port only (DEC-082).
- `aftercare_otp_verify(p_token_hash, p_otp_hash, p_session_hash, p_now)`: link expiry, lock, otp_expires_at; a wrong code → attempts + 1;
  the 5th → otp_locked_until = now + 15 min, OTP fields cleared; returns { ok: false, reason: otp_invalid | otp_locked, attempts_remaining }
  (committed). A match → OTP cleared, opened_at = coalesce(opened_at, now), session_hash stored, session_expires_at = least(expires_at,
  now + 30 min); the session cookie (httpOnly, SameSite=Lax, Secure in production, Path=/aftercare) carries the session token (plain only
  in the cookie).
