## What the command is

As T-032 (`m0`) and T-049 (`m1`) found: `pnpm test -- m2` is not a filter — vitest receives `m2` after `--` and runs every file, so it is the whole suite on a real PostgreSQL. The M2 scenarios and CLIN items are tied to exact test cases by a map, checked against a JUnit report of that run.
