## Design

**Module `src/modules/patients/profile.ts`** (no migration):
- `PROFILE_SECTIONS` and `profileSections(role)`: the role projection, one pure function, the single source the page and tests use.
  - Every identity reader: `ringkasan` (identity, birth date/age, sex, MRN, registered branch, phone, address), `wali` (guardians), `persetujuan` (consents), `kunjungan`, `paket-saldo`.
  - Clinical sections, clinical roles only:
    - `rekam-medis`: doctor, facility head, records officer, nurse, therapist;
    - `foto`: doctor, facility head, records officer, BC, nurse, therapist (PR-9: BC takes intake photos);
    - `resep`: doctor, pharmacist, facility head, records officer.
  - Non-clinical roles (owner, admin pusat, manager, FO/cashier, central CS, finance) get no clinical section. Marketing, purchasing and auditor have no profile (forbidden).
- `loadProfile(db, id)`: `getPatient` (the database decides role and tenant; unknown → null, audited) plus `patientConsents`; the role's sections; `canRecordConsent` (the six recorders).
- Sections whose owners are later tasks (visits T-047, packages/balance M4, clinical content M2) render an honest "belum tersedia" line, never an empty list that would read as "none". Clinical sections are only placeholders here, so no clinical data is read and nothing is audited yet; the audit-on-open lands with the first clinical content (open point 2).

**Page `src/app/(app)/pasien/[id]/`** (`page.tsx`, `data.ts`, `actions.ts`, `forms.tsx`, `labels.ts`):
- `DetailPage` with the role's sections; header: name, MRN, age; identity type shown, the number never (open point 1).
- Persetujuan: rows with purpose, text version, date, channel, status; recorders get "Catat Persetujuan" (purpose, channel; current text shown before confirming) and "Tarik Persetujuan" (channel, reason ≥ 3) per active row except the care notice. Actions refuse a stale context (HYG-009), carry an idempotency key, map `ConsentError` / `GoLiveBlockedError` to copy.
- Forbidden role → `PermissionState`; unknown or foreign id → not found.
